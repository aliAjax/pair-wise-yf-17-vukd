# 管风琴音管调音台

给管风琴维护人员使用的调音记录应用：预置两场馆、三音栓、八根音管，逐管记录音高、音分偏差、簧片状态与维修备注。

## 业务规则

- **开工先填环境读数**：维护开始先登记温湿度基线（第一条读数），未登记前不能测量音管。
- **结项条件**：同一音栓的音管全部测完，且温度、湿度相对基线的变化各不超过 ±10%，才能结项并存档。
- **环境读数联动复测**：追加或改动任一读数后，已测音管全部转为「待复测」，原测量值冻结只读；已结项音栓不受影响。
- **单管复核**：复测保存只恢复本管状态，不影响其他音管。
- **偏差表 / 异常标记 / 单次报告同源**：偏差超 ±10 cent 自动标异常，偏差表、异常标记和报告由同一份判定数据派生，实时同步。
- **数据存浏览器**：会话与结项报告通过 `localStorage` 持久化，报告为结项时刻的快照，可调阅、打印。

## 模块划分

- `src/domain/rules.ts` —— 判定模块：异常阈值、温湿度变化、结项判定、报告生成。
- `src/domain/store.ts` —— 存档模块：维护会话状态流转（开工、读数、测量、复测、结项、结束）与浏览器持久化。
- `src/ui/` + `src/App.tsx` —— 界面模块：场馆开工页、环境读数、调音偏差表、报告与存档查看。
