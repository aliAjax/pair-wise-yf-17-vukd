# 管风琴音管调音台

给管风琴维护人员使用的音管调音记录前端。预置 **两场馆、三音栓、八根音管**，每根音管记录音高、音分偏差（实测频率按 cent 公式同步反算）、簧片状态与维修备注。

## 业务规则

- **维护开始先填环境读数**：温湿度基准读数未填前，音管测量锁定。
- **结项条件**：同一音栓的音管全部测完，且温度、湿度相对基准读数的变化各不超过 **10%**（温度先换算开尔文再算相对差），无待复测音管、无偏差超限音管，才能结项存档。
- **环境读数联动**：追加、改动或删除环境读数时，该场馆全部已测音管转为 **待复测**，原测量值 `sealed` 只读封存；**单管复核**只给本管追加一条新测量，仅恢复本管。
- **偏差表 / 异常标记 / 单次报告同源同步**：均由判定模块的 `buildStopReport` 实时投影；|偏差| ≥ 10 音分标红为异常，5–10 音分标临界。
- 结项后报告冻结进**维护存档**，数据保存在浏览器 `localStorage`（键 `organ-tuning-console:v1`）。

## 模块划分

- `src/domain/rules.ts` —— **判定模块**：异常阈值、温湿度漂移、单管状态、结项检查与报告投影（纯函数）。
- `src/domain/store.ts` —— **存档模块**：localStorage 读写、读数/测量状态流转、结项冻结。
- `src/ui/` —— **界面模块**：调音台、维护报告、维护存档三个页面及组件。
- `src/data/catalog.ts` —— 场馆 / 音栓 / 音管预置目录。
